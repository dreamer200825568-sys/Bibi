# EnglishBuddy prototype
A mobile-first, browser-based A1 learning prototype inspired by the Sundarbans.

## Run
Open `index.html` in a modern browser, or deploy the folder as a static site (GitHub Pages, Netlify, Replit static site).
No build step or API key is required.

## Included
- Sundarbans-inspired home environment using an original generated visual
- Separate distraction-free lesson workspace
- Five A1 sample lessons with ten vocabulary items each
- Vocabulary flashcards and browser speech synthesis
- Pattern discovery, guided sentence building and independent writing attempt
- Teach Bablu sample interactions
- Story, listening, speaking and writing prototypes
- Progress saved in localStorage and JSON export
- Mobile responsive layout and reduced-motion support

## Prototype limitations
- Progress is local to one browser/device; no account or cloud sync.
- Speech synthesis depends on installed browser/device voices.
- Speech-to-text, pronunciation scoring and AI evaluation are not implemented.
- Skill indicators are illustrative activity metrics, not validated CEFR scores.
- Only the initial A1 demonstration content is populated; A2-C2 are architecture placeholders.
- Lesson checks are intentionally simple prototype checks, not a complete assessment engine.
